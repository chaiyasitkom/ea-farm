## 5. ⚠️ ช่องว่างเชิงโครงสร้างที่ยังไม่มีใครแตะ

### 5.1 ไม่มี git remote = ไม่มี backup

repo อยู่บนเครื่องเดียว · เครื่องพัง = **หายทั้งหมด** รวมทั้ง ADR และ spec ที่ใช้เวลาสร้าง
**ควรทำก่อนอย่างอื่น** — เป็นงานนาทีเดียว ความเสี่ยงสูงสุดต่อความพยายามต่ำสุด

### 5.2 G3 ยังไม่ตัดสิน → SPEC-009 (CI) เขียนไม่ได้

GitHub Actions **รัน MQL5 test ไม่ได้** (ไม่มี MetaEditor/MT5)
และส่วนที่สำคัญที่สุดของระบบ (EA · risk guard · order router) **เป็น MQL5 ทั้งหมด**

ทางเลือกที่เป็นไปได้จริง:

| | ทางเลือก | ผล |
|---|----------|-----|
| ก | CI = Python เท่านั้น (ruff/mypy/pytest/codegen-check) · MQL5 gate รันมือบนเครื่องนี้ | ตรงกับความเป็นจริง · **แต่ regression ของ MQL5 จับได้เฉพาะตอนมีคนรัน** |
| ข | self-hosted runner บนเครื่อง Windows นี้ | อัตโนมัติจริง · ต้องมี remote ก่อน · ตั้งครั้งเดียว |
| ค | ไม่มี CI เลย ใช้ `make check` + gate ก่อน handoff ทุกครั้ง | ง่ายสุด · พึ่งวินัยล้วน |

**ผมแนะนำ ข** — แต่ต้องมี remote (§5.1) ก่อน · **เจ้าของตัดสิน**

### 5.3 Phase 2 มีของที่ต้องซื้อ/ตั้งค่านอกโค้ด

VPS (D7) · Telegram bot token · บัญชี demo ที่ 2 · ทุน live (D5 เลื่อนไปจบ Phase 2)
