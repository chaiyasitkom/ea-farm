## 🔴 B4 — throttle มาแล้ว แต่ implement ด้วย `LocalTime()` → **สร้างบั๊กใหม่ที่แรงกว่าเดิม**

`BrokerTime.mqh:157-168`

```mql5
const datetime local_now = m_src.LocalTime();
if(m_last_sample_local > 0 && local_now > 0 && local_now - m_last_sample_local < 20)
{
   if(m_bad_sample_started_local > 0 && local_now - m_bad_sample_started_local > 90)
   { m_valid = false; m_candidate_count = 0; }
   return false;
}
```

[rev.2a §4.3.1](../specs/SPEC-063-broker-time.md) เขียนไว้ชัดว่า **ต้องวัดด้วย `GmtTime()`
ห้ามใช้ `LocalTime()`** และอธิบายเหตุผลไว้แล้ว (finding B16) · รอบนี้ไม่เพียงไม่แก้ B16
แต่**ขยาย `LocalTime()` เข้าไปในเส้นทาง throttle ด้วย** ทำให้ผลกระทบกว้างขึ้น

### ทำไมถึงแรงกว่าที่คิด — `datetime` ใน MQL5 เป็น unsigned

`datetime` เป็นจำนวนเต็ม **ไม่มีเครื่องหมาย** → `local_now - m_last_sample_local`
เมื่อนาฬิกา local **ถอยหลัง** จะ **underflow เป็นค่าบวกมหาศาล** ไม่ใช่ค่าลบ

| เหตุการณ์ | `local_now - m_bad_sample_started_local` | ผลจริง |
|-----------|------------------------------------------|--------|
| DST เดินหน้า (+1 ชม.) | `+3600` | `> 90` → **invalidate ทันที** ทั้งที่ทุกอย่างปกติ |
| DST ถอยหลัง (−1 ชม.) | **underflow → ~1.8×10¹⁹** | `> 90` → **invalidate ทันที** เช่นกัน |

→ **นาฬิกา VPS ขยับเมื่อไร ถ้ามีหน้าต่าง bad-sample เปิดอยู่ EA จะเข้า SafeMode ทันทีโดยไม่มีเหตุ**
· ปีละ 2 ครั้งเป็นอย่างน้อย และทุกครั้งที่ NTP แก้เวลาเป็นก้อน

> ผมจงใจไม่ฟันธงว่าจะออกทางไหนแน่ระหว่าง "invalidate ทันที" กับ "ค้างไม่ตรวจ 1 ชั่วโมง"
> เพราะขึ้นกับ signedness ที่ MQL5 ไม่ได้รับประกันชัดในเอกสาร — **แต่ทั้งสองทางผิดทั้งคู่**
> และการที่ต้องมานั่งเดาว่าจะออกทางไหน คือเหตุผลที่ควรใช้ `GmtTime()` + cast เป็น `long` ให้จบ

**ต้องแก้:**

```mql5
const long now_gmt = (long)m_src.GmtTime();
if(m_last_sample_gmt > 0 && now_gmt > 0 && now_gmt - m_last_sample_gmt < 20) …
```

- ใช้ `GmtTime()` ทั้ง throttle และหน้าต่าง 90 วินาที
- **cast เป็น `long` ก่อนลบเสมอ** — ห้ามลบ `datetime` ตรงๆ ที่ไหนอีก
- เปลี่ยนชื่อฟิลด์ `m_last_sample_local` / `m_bad_sample_started_local` → `_gmt`
  ให้ชื่อบอกความจริง (ตอนนี้ชื่อบอกถูก แต่บอกว่ากำลังทำสิ่งที่ผิด)

### B18 🟠 ใหม่ · ตรรกะ 90 วินาทีถูกเขียนไว้ **2 ที่**

`BrokerTime.mqh:160-164` (ในเส้น throttle) และ `:106-110` (`MarkBadSample`)
· state machine ที่มีสองสำเนาจะค่อยๆ ต่างกัน · รวมเหลือที่เดียว แล้วให้ throttle เรียกมัน

```
  exit 3
```

`exit 3` ยังไม่ใช่ 0 → **ยังแดง ยังบล็อก** แต่ script ข้างบนแยกได้ว่าเป็นสิ่งแวดล้อมหรือ regression
· ข้อความนี้ควรลงเป็นขั้นตอนใน runbook [SPEC-030b](../specs/SPEC-028-dashboard-kill-switch.md) ด้วย
