### ② MT5 whitelist — **ตัดสินแล้ว**

**พอร์ตมาตรฐานของ live chaos = `45001`** (override ได้ด้วย `EA_FARM_CHAOS_PORT`)

**ให้ใส่ whitelist ทั้ง 2 บรรทัด:**

```
127.0.0.1
127.0.0.1:45001
```

**เหตุผลที่ใส่ทั้งคู่:** เรายัง**ไม่รู้**ว่า MT5 build นี้ต้องการรูปแบบไหน และการเดาผิดหนึ่งครั้ง
แลกด้วยการรันใหม่ 5 นาที · การใส่ทั้งคู่ราคาเป็นศูนย์และตัดตัวแปรออกจากสมการทันที
· ถ้าติดแล้ว ค่อยทดลองลบทีละบรรทัดเพื่อรู้ว่าอันไหนจำเป็น **แล้วบันทึกผลลง runbook**

**ต้องบันทึกเป็นขั้นตอน setup บังคับ** (จะย้ายเข้า SPEC-030b):

| ขั้น | ทำ |
|------|-----|
| 1 | `Tools → Options → Expert Advisors` |
| 2 | ✅ **Allow Algo Trading** |
| 3 | ✅ **Allow WebRequest for listed URL** ← ถ้าไม่ติ๊ก รายการข้างล่างถูกละเลยทั้งหมด |
| 4 | เพิ่ม `127.0.0.1` **และ** `127.0.0.1:45001` |
| 5 | **ปิด terminal ให้สนิท** แล้วเปิดใหม่ (setting เขียนลง `settings.ini` ตอนปิด) |

ข้อ 5 สำคัญ — harness **kill** terminal ทุกครั้ง ซึ่งไม่เขียน setting กลับ
ดังนั้นการตั้งค่าต้องทำในรอบที่ปิดเองด้วยมือ

**เพิ่ม preflight ใน `run-chaos.ps1`:** ก่อนรัน suite ให้เปิด socket ฟังที่พอร์ตนั้นเองแล้วตรวจ

ดีกว่าปล่อยให้ไปตายที่ test แล้วโทษ EA

### ③ `[Experts]` ใน startup ini — **ยังไม่ต้องแก้ · ห้ามเดา**

**คำตอบสั้น: ยังไม่อนุมัติให้แก้ในตอนนี้**

เหตุผล: เรามีสมมติฐาน 2 ข้อที่ยังแยกกันไม่ออก และการแก้ตอนนี้คือการเดา

| สมมติฐาน | ทดสอบยังไง |
|----------|-----------|
| **A** whitelist ยังไม่ match (ค่าผิดรูปแบบ) | ใส่ทั้ง 2 บรรทัดตาม ② แล้วรันใหม่ |
| **B** `[Experts]` ใน ini รีเซ็ต setting ตอน start | เปิด terminal **เองแบบไม่ผ่าน `/config`** แล้วลาก EA ใส่กราฟ |

**ลำดับที่ต้องทำ:**

1. ใส่ whitelist ทั้ง 2 บรรทัด → รัน `run-chaos.ps1` → **ถ้าเขียว จบ ไม่ต้องแตะ ini เลย**
2. ถ้ายังแดง → เปิด terminal เองแบบไม่ผ่าน `/config` ต่อ `127.0.0.1:45001`
   - **ต่อติด** → ยืนยันสมมติฐาน B → ทำข้อ 3
   - **ยังไม่ติด** → เป็น A · ปัญหาอยู่ที่ค่าใน whitelist **`[Experts]` ไม่เกี่ยว ห้ามแตะ**
3. **ถ้าและต่อเมื่อยืนยัน B แล้ว** — ให้แก้แบบนี้:
   ```
   ลบทั้งบล็อก [Experts] ออก เหลือแค่ [StartUp]
   ```
   **ไม่ใช่**ลบทีละคีย์ · เหตุผล: setting พวกนี้ terminal จำอยู่แล้วใน `settings.ini`
   การเขียนทับตอน start เป็นของซ้ำซ้อนตั้งแต่แรก · และ **การให้ harness รันบน setting
   ชุดเดียวกับ production คือสิ่งที่เราต้องการอยู่แล้ว** ไม่ใช่ชุดที่ harness แต่งขึ้นเอง
   · ผลข้างเคียงที่ยอมรับ: ต้องพึ่ง "Allow Algo Trading" จาก GUI → **เขียนลง runbook ข้อ 2**

> **หลักการที่ใช้ตัดสิน:** ตอนนี้มี 2 ตัวแปรที่เปลี่ยนพร้อมกันไม่ได้
> ถ้าแก้ทั้ง whitelist และ ini พร้อมกันแล้วเขียว **เราจะไม่มีวันรู้ว่าอะไรคือสาเหตุ**
