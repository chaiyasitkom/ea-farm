## 1. 🔴 `/1000` **ไม่ใช่ต้นเหตุ** — ทำแค่ S1(a) แล้วจะไม่หาย

ผมเขียนใน work-order ว่าต้นเหตุคือ *"การปัดเศษวินาที"* · **ผิด** พิสูจน์ด้วยเลขคณิต:

```
floor(e/1000) >= K   ⟺   e >= K*1000      ← ตรงเป๊ะ ไม่มีอคติเลยแม้แต่ ms เดียว
```

ทุกจุดที่เทียบ `>=` / `<` ยิงตรงเวลาพอดี **`ElapsedSec()` ไม่ได้ทำให้ heartbeat เพี้ยน**

### ต้นเหตุจริง = ฐานรีเซ็ต + `EventSetTimer(1)`

```mql5
EventSetTimer(1);                    // FarmExecutor.mq5:80  ← poll ได้แค่ทุก 1 วินาที
m_last_heartbeat_tick = NowTick();   // Wire.mqh:612         ← ฐานเลื่อนตามเวลาส่งจริง
```

ฐานขยับออกจากเส้น tick ทีละนิดทุกรอบ → tick ที่ 2 เห็น `e = 1999` → พลาด → **รอถึง tick ที่ 3**
= histogram `{2.0: 376, 3.0: 276}` ที่วัดได้ **ตรงเป๊ะ**

> **⛔ ถ้าทำแค่ (a) เปลี่ยนไปเทียบ ms แล้วยังคง `= NowTick()` → บั๊กอยู่ครบ**
> **(b) `next_due += 2000` คือข้อที่แก้จริง** เพราะฐานอยู่บนเส้น tick ตลอด ไม่มีวันหลุด
> (a) ยังต้องทำ แต่เป็นของที่ทำให้ (b) เขียนได้ · **(c) (d) คงเดิม**

## 3. 🔴 S4 (ใหม่) — brain timeout ยิงช้าไป **1 วินาทีเต็ม**

```mql5
// FarmExecutor.mq5:14   InpBrainTimeoutSec = 10
// FarmExecutor.mq5:109
if(g_wire.IsAuthenticated() && g_wire.SecondsSinceLastInbound() > InpBrainTimeoutSec)
```

`floor(e/1000) > 10` ⟺ **`e >= 11,000 ms`** → ตั้ง 10 วินาที ยิงจริง **11.000 วินาที**

วันนี้แค่ `Warn` ช้า · **แต่เมื่อ SPEC-023 ขึ้น นี่คือ R16 → SafeMode**
และ **Phase 1 exit บังคับ "kill brain → SafeMode ≤ 10s"** → **ตกเกณฑ์ทันทีด้วยเหตุที่เดาไม่ถูก**

**แก้ (แนะนำ):** เพิ่ม `MsSinceLastInbound()` คืน `uint` → `:109` เทียบ `>= InpBrainTimeoutSec * 1000`

## 4. 🟠 S5 (ใหม่) — `:786` เทียบ unsigned ดิบ ซึ่ง S1(d) ห้ามไว้เอง

```mql5
if(m_state == WIRE_DISCONNECTED && NowTick() < m_next_connect_tick)   // Wire.mqh:786
```

ผมไล่ทั้งสองเคสของ wrap แล้ว — **ไม่ใช่การค้างถาวร** · ผลคือ backoff ถูกข้าม 1 ครั้ง
ทุก ~49.7 วันของ uptime (reconnect เร็วกว่ากำหนดสูงสุด 30 วินาที)

**แก้:** `if((int)(NowTick() - m_next_connect_tick) < 0) return;`

> **S5 คือหลักฐานว่าข้อ 1 ถูก** — อันตรายของ unsigned อยู่ที่ **การเปรียบเทียบ** (`:786`)
> ไม่ใช่ **การลบ** (`:128`) · คำสั่งเดิมของผมชี้ผิดจุดทั้งคู่
