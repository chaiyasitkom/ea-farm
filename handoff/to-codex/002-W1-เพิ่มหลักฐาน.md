# W1 · หลักฐานใหม่ — TCP ต่อสำเร็จจริง และผมตัดสมมติฐานทิ้งได้ 1 ข้อ

ผมรัน `test_ea_reconnects_after_server_kill` เองอีกรอบ (2026-07-31 01:35) โดย**ล้าง chart profile ก่อน**
(W3) เพื่อให้มี EA ตัวเดียว แล้วเก็บ log **สองฝั่งพร้อมกัน**

## ★ หลักฐานที่เปลี่ยนภาพทั้งหมด — ฝั่ง server

```json
{"event":"connect",      "wall_time":"2026-07-30T18:35:37Z","monotonic":136751.703}
{"event":"client_closed","wall_time":"2026-07-30T18:35:37Z","monotonic":136751.718}
{"event":"disconnect",   "wall_time":"2026-07-30T18:35:37Z","monotonic":136751.718}
```

**TCP ต่อสำเร็จจริง — server `accept()` ได้ — แล้ว EA ปิดเองภายใน 15 มิลลิวินาที**

`client_closed` แปลว่า **ฝั่ง EA ปิด** ไม่ใช่ server timeout
· ตรงกับ `SendBytes()` ที่เรียก `CloseSocket()` ทันทีเมื่อ `SocketSend` คืนค่าติดลบ

| สรุปได้ว่า | |
|---|---|
| ✅ `SocketConnect` สำเร็จจริง ไม่ใช่แค่คืน true | server เห็น connection |
| ✅ TCP handshake จบแล้ว | server `accept()` ผ่าน |
| ❌ **`SocketSend` ล้มบน socket ที่ต่อติดแล้ว** | นี่คือขอบเขตของบั๊ก |

## ตัดสมมติฐานข้อ 3 ทิ้ง — ผมตรวจเองแล้ว

`SendRawLine()` (`Wire.mqh:318-336`) สร้าง buffer **ถูกต้อง**:

```mql5
const int total = StringToCharArray(frame, data, 0, WHOLE_ARRAY, CP_UTF8) - 1;  // ตัด null ท้าย ✅
ArrayResize(data, total);                                                        // ขนาดพอดี ✅
SocketSend(m_socket, data, (uint)total);                                         // total == ArraySize(data) ✅
```

**ไม่ต้องเสียเวลาไล่ข้อนี้**

## 🔴 สมมติฐานใหม่ที่ผมคิดว่าน่าจะใช่ที่สุด — `SocketTimeouts()` ไม่เคยถูกเรียกเลย

```
grep -rn "SocketTimeouts" mt5-ea/   →   ไม่เจอสักบรรทัด
```

MQL5 มี `SocketTimeouts(socket, timeout_send_ms, timeout_receive_ms)` สำหรับตั้ง timeout
ของ **send/receive** แยกจาก timeout ของ `SocketConnect` (`m_connect_timeout_ms = 3000`
ซึ่งคุมแค่ตอนต่อ ไม่คุมตอนส่ง)

**ถ้า default ของ send timeout เป็น 0** → `SocketSend` จะล้มทันทีเมื่อ socket
ยังไม่พร้อมเขียนในเสี้ยววินาทีนั้น แทนที่จะรอ — ซึ่งอธิบาย **15 มิลลิวินาที** ได้พอดี
และอธิบายว่าทำไมล้ม **100%** ไม่ใช่บางครั้ง

**ลองเรียกทันทีหลัง `SocketConnect` สำเร็จ:**

```mql5
EnterState(WIRE_CONNECTED);
SocketTimeouts(m_socket, 3000, 3000);   // ← ทดสอบข้อนี้ก่อน
m_log.Info(StringFormat("socket_connected host=%s port=%d", m_host, m_port));
SendHello();
```
