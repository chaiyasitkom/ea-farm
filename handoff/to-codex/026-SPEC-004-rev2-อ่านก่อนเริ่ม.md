## 3 ข้อที่กระทบวิธีทำงานจริง ไม่ใช่แค่ถ้อยคำ

### C5 — fixture ต้องเดินทางจาก repo ไปถึง `Common\Files`

`contracts/fixtures/` อยู่ในรีโป · MQL5 อ่าน path นอก sandbox ไม่ได้
→ **`run-mql5-tests.ps1` ต้องก๊อปให้ก่อนรันทุกครั้ง** และ **ลบทั้งโฟลเดอร์ก่อนก๊อป**
(หลักการเดียวกับ T1 — ของค้างจากรอบก่อนทำให้ผลรันเชื่อไม่ได้)

- ไฟล์ใน `invalid/` ใช้ prefix **`invalid__`** แทนโฟลเดอร์ย่อย
- เขียนด้วย **`FILE_BIN` + `CP_UTF8`** ห้าม `FILE_UTF8` — ไทยใน `comment` จะเพี้ยน
- **test ต้อง fail ถ้าโฟลเดอร์ว่าง** — ห้ามเขียวเพราะไม่มีไฟล์ให้ทดสอบ (bug class T2)

⚠️ นี่คือการแตะ `tools/**` → **เขียนใน handoff ว่าแก้อะไร** ผมอ่าน diff ของ gate ก่อนดูผลรันเสมอ

### C6 — เกณฑ์ memory เดิมวัดไม่ได้จริง

`TERMINAL_MEMORY_USED` มีหน่วยเป็น **MB** → เกณฑ์ "ไม่เกิน 5 MB" คือ resolution แค่ **5 ขั้น**
แยก leak ออกจาก noise ไม่ได้ · เปลี่ยนเป็นเก็บ **20 จุด** (ทุก 500 รอบ) แล้วดู **slope ของครึ่งหลัง ≤ 0**
· ครึ่งแรกยอมให้โตจาก warm-up ของ allocator

### C8 — `import farm_contracts` จะพังถ้าไม่มีใครใส่

SPEC-002 rev.2 ตั้ง `package-dir` ไว้แล้วแต่**จงใจไม่ใส่ `farm_contracts` ใน `packages`**
เพราะตอนนั้น `contracts/gen/python/` ยังไม่มี → **ticket นี้เป็นคนใส่**
เป็นข้อยกเว้นเดียวที่ SPEC-004 แตะ `pyproject.toml` ได้
