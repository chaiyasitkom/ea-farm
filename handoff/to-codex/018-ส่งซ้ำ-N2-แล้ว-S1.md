## รอบ 1a — N2 + N3

### N2 · `test_wire_resilience.py`

| # | ทำ |
|---|-----|
| **a** | **แยกเกณฑ์เป็นสองตัว** — watchdog ในลูปตั้งที่ **10s** (ไว้ fail เร็ว ไม่ต้องรอครบชั่วโมง · C12) · ส่วน **`max_gap ≤ 3.5s` คำนวณหลังรอบจบจาก event log** |
| **b** | `read_events()` เลิกอ่านทั้งไฟล์ทุก 0.5 วินาที → **จำ offset แล้วอ่านต่อจากเดิม** |

คือเหตุที่เกณฑ์ในลูปเชื่อไม่ได้ตั้งแต่ต้น (ตกที่ **3.547s เกินเกณฑ์แค่ 47 ms**)

## รอบ 1b — S1 + S2 + S3 (หลัง 1a ผมตรวจผ่านแล้วเท่านั้น)

**หลักฐาน 653 ตัวอย่าง:** `mean_gap = 2.436s` · `histogram = {2.0: 376, 3.0: 276}`
มีแค่จำนวนเต็มสองค่า = **การปัดเศษวินาที** ไม่ใช่ jitter

### S1 · ต้นเหตุ `Wire.mqh:126-129` + `:612`

```mql5
return (int)((NowTick() - since_tick) / 1000);   // ← 1999 ms = 1 วินาที
...
m_last_heartbeat_tick = NowTick();               // ← ฐานรีเซ็ตเป็นเวลาส่งจริง
```

| # | ต้อง | ห้าม |
|---|------|------|
| **a** | เทียบด้วย **มิลลิวินาที** | ห้ามใช้ `>= InpHeartbeatSec` กับค่าที่ `/1000` แล้ว |
| **b** | เลื่อนฐานแบบ **`next_due += interval`** | ห้าม `= NowTick()` |
| **c** | ตกหลังหลายรอบ → **ตามให้ทันโดยไม่ยิงรัว** | ห้ามส่งชดเชยย้อนหลังทีเดียวหลายอัน |
| **d** ★ | **cast เป็น signed ก่อนเทียบเสมอ** | ห้าม `NowTick() >= m_next_heartbeat_tick` ตรงๆ |

⚠️ **ข้อ d — กับดัก unsigned ครั้งที่สองของโปรเจกต์นี้** · `GetTickCount()` เป็น `uint`
**wrap ทุก ~49.7 วัน** · ตระกูลเดียวกับ **B16b** ใน SPEC-063 · ครั้งนั้น EA เข้า SafeMode ฟรี
**ครั้งนี้ผลคือ heartbeat หยุดถาวรจนกว่าจะรีสตาร์ต**
